# คู่มือการติดตั้งและใช้งาน MySQL Database บนโฮสต์ Vornyx

ระบบนี้รองรับ 2 โหมดการทำงานอัตโนมัติ:
1. **Localhost (ในเครื่องตัวเอง):** หากไม่มีการตั้งค่าตัวแปร MySQL ระบบจะอ่านและบันทึกไฟล์ `.json` ในโฟลเดอร์ `data/` เหมือนเดิม 100%
2. **Production (ออนไลน์จริง):** เมื่อตั้งค่าตัวแปร MySQL ใน `.env.local` หรือ Vercel ระบบจะบันทึกข้อมูลทุกอย่างลงฐานข้อมูล MySQL บนโฮสต์ Vornyx ของคุณทันที ข้อมูลไม่หายถาวร 100%

---

## 📁 ไฟล์ที่เตรียมไว้ให้ในโฟลเดอร์นี้:
- **`setup.sql`**: สคริปต์สร้างตาราง `gang_storage` พร้อมข้อมูลเริ่มต้นทั้งหมดของแก๊ง (ดึงมาจากไฟล์ JSON ปัจจุบันครบทุกไฟล์)

---

## 🚀 ขั้นตอนการติดตั้งบนโฮสต์ Vornyx (DirectAdmin / cPanel)

### ขั้นตอนที่ 1: สร้างฐานข้อมูล MySQL บนโฮสต์
1. ล็อกอินเข้าแผงควบคุมโฮสต์ (DirectAdmin หรือ cPanel) ของโดเมน `vornyx.pro`
2. ไปที่เมนู **MySQL Management** หรือ **MySQL Databases**
3. กดสร้าง **Database ใหม่** และสร้าง **User + Password**
4. กำหนดสิทธิ์ให้ User นั้นเข้าถึง Database ได้แบบ **ALL PRIVILEGES**

---

### ขั้นตอนที่ 2: นำเข้าข้อมูล (Import SQL)
1. เข้าไปที่ **phpMyAdmin** บนโฮสต์ของคุณ
2. เลือกฐานข้อมูลที่เพิ่งสร้างขึ้นมา
3. ไปที่แท็บ **Import (นำเข้า)** -> เลือกไฟล์ `mysql/setup.sql` -> กด **Go (ดำเนินการ)**  
   *(หรือไปที่แท็บ SQL แล้วก๊อปปี้เนื้อหาในไฟล์ `mysql/setup.sql` ทั้งหมดมาวางแล้วกดรันได้เลย)*

---

### ขั้นตอนที่ 3: เปิดสิทธิ์ Remote MySQL (จำเป็นหากเว็บอยู่บน Vercel)
หากคุณนำเว็บไปรันบน Vercel คุณต้องอนุญาตให้ภายนอกเชื่อมต่อเข้ามายัง MySQL ได้:
1. ใน cPanel / DirectAdmin มองหาเมนูชื่อ **Remote MySQL** (หรือ **Access Hosts**)
2. ในช่อง **Host (% wildcard is allowed)** ให้พิมพ์เครื่องหมาย:
   ```
   %
   ```
3. กด **Add Host** เพื่ออนุญาตให้ Vercel เชื่อมต่อเข้ามาบันทึกข้อมูลได้

---

### ขั้นตอนที่ 4: ตั้งค่าตัวแปรใน `.env.local` หรือ Vercel Dashboard

นำค่าการเชื่อมต่อ MySQL มาใส่ในไฟล์ `.env.local` (ในเครื่อง) หรือใน **Vercel Project Settings -> Environment Variables**:

```env
# ==========================================
# MYSQL DATABASE (VORNYX)
# ==========================================
MYSQL_HOST=vornyx.pro
MYSQL_PORT=3306
MYSQL_USER=ชื่อผู้ใช้_mysql_ของคุณ
MYSQL_PASSWORD=รหัสผ่าน_mysql_ของคุณ
MYSQL_DATABASE=ชื่อฐานข้อมูล_mysql_ของคุณ
```

*(หมายเหตุ: `MYSQL_HOST` ให้ใส่เป็นโดเมนโฮสต์ เช่น `vornyx.pro` หรือหมายเลข IP ของโฮสต์ของคุณ)*
